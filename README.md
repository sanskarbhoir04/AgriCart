# 🌾 AgriCart

AgriCart is an agriculture-focused e-commerce web application designed to provide a digital marketplace for agricultural products.

## 🌐 Project Links

### 🚀 Live Website
https://agricart-k2ze.onrender.com

### 💻 GitHub Repository
https://github.com/sanskarbhoir04/AgriCart

## ✨ Features

- User Registration & Login
- Product Browsing
- Product Search
- Shopping Cart
- Order Management
- Seller Management
- User Address Management
- Notifications
- Admin Management
- Agricultural Product Management
- Responsive Web Interface

## 🗄️ Database

The application uses MySQL for storing users, products, orders, cart information, seller information and other application data.

The production database is hosted on Aiven Cloud.
